# Карта Пространства (TTK Hackathon Solution)

Интерактивный веб-сервис для внутренней навигации, создания 2D-планов помещений и просмотра 360°-панорам здания.

---

## 🚀 Основные возможности

### 🏢 Для Организаторов и Администраторов (`Editor`)

* **Редактор 2D-планов:** Разметка помещений, коридоров, зон и стеллажей.
* **Съемка и загрузка панорам (`PanoCapture`):** Пошаговое создание круговых панорам прямо с камеры телефона или загруженных изображений.
* **Интерактивные метки (POI):** Размещение точек интереса (стенды, Wi-Fi, входы, стойки регистрации) с описаниями и переходами между панорамами.
* **Публикация:** Мгновенное обновление карты без изменения постоянной ссылки.

### 🧭 Для Посетителей (`Visitor` / `Viewer`)

* **Интерактивный просмотр:** Исследование комнат и точек на 2D-плане.
* **3D-Виртуальный тур:** Перемещение между связанными панорамами и просмотр карточек объектов.
* **Построение маршрутов:** Пошаговая навигация от точки «А» до точки «Б» внутри здания с отображением пути на схеме.
* **Mobile-First UX:** Адаптированный и быстрый интерфейс для работы с мобильных устройств.

---

## 🛠 Технологический стек

* **Frontend:** [React](https://react.dev/) + JavaScript (ES6+)
* **Сборщик:** [Vite](https://vitejs.dev/)
* **Стилизация:** CSS3 (Custom Styles / Responsive Design)
* **Линтинг и качество кода:** [Oxlint](https://oxc-project.github.io/)
* **Backend:** Node.js + ESM HTTP server для auth, карт и загрузки файлов

## 📦 Установка и запуск

### Предварительные требования

* **Node.js** версии `18.x` или выше
* **npm** или **yarn**

### 1. Клонирование репозитория и установка зависимостей

```bash
git clone <repository-url>
cd ttk_hack-master
npm install
```

### 2. Запуск backend

В корне проекта есть локальный сервер `server.js`, который отвечает за:
- регистрацию и логин: `/api/auth/register`, `/api/auth/login`
- хранение карт: `/api/maps`, `/api/maps/:id`
- загрузку изображений: `/api/upload`
- статические файлы в `/uploads/...`

Запуск:

```bash
node server.js
```

Проверка:

```bash
curl http://127.0.0.1:3000/api/health
```

Ожидаемый ответ:

```json
{"ok":true,"service":"ttk_hack-backend"}
```

### 3. Настройка окружения frontend

Скопируйте пример env-файла:

```bash
cp .env.example .env
```

По умолчанию там уже есть:

```env
PORT=3000
VITE_API_TARGET=http://127.0.0.1:3000
```

Если backend запущен на другом хосте или порту — поменяйте значение `VITE_API_TARGET`.

### 4. Запуск frontend в режиме разработки

```bash
npm run dev
```

После запуска откройте локальный адрес в браузере, обычно это:

```text
http://localhost:5173
```

### 5. Сборка для production

```bash
npm run build
```

Готовую сборку можно посмотреть локально:

```bash
npm run preview
```

## 🧪 Проверка регистрации

После запуска backend и frontend можно протестировать регистрацию через API:

```bash
curl -X POST http://127.0.0.1:3000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com","password":"123456"}'
```

Ожидаемый ответ:

```json
{"token":"...","user":{"id":"user_...","email":"user@example.com"}}
```

## 📝 Особенности реализации

* **Быстрая загрузка:** Оптимизированный рендеринг панорам и легкий 2D-план гарантируют высокую скорость работы.
* **Интуитивный интерфейс:** Интерфейс подсказывает порядок действий при съемке панорам с телефона.
* **Локальное хранилище для MVP:** Для хакатона данные хранятся локально на диске, без внешней базы данных.
* **Готовность к расширению:** Архитектура позволяет заменить JSON-хранилище на базу данных и добавить авторизацию, админку и API для мобильных клиентов.

## 📌 Примечание

Если вы открываете проект локально, обязательно запускайте backend до использования функций авторизации, загрузки карт и панорам. Без живого `server.js` фронтенд будет обращаться к несуществующему API и получать ошибки вроде `502` или `401`.
